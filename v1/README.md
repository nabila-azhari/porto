# Nabila Azhari Portfolio - Version 1 (v1)

This folder contains the complete, standalone codebase for **Portfolio Version 1**.

### Theme & Concept
- **Style**: Dark Cyber-Green Holographic / Bento Grid AI Portfolio
- **Key Features**:
  - Interactive Glowing Custom Cursor
  - Dynamic Floating Navigation Header with Mobile Support
  - Interactive Filterable Selected Work & AI Engineering Projects
  - Data & Machine Learning Interactive Case Studies & Metrics
  - Interactive Project Modal / Lightbox with Deep Dive Details
  - Research & Publications & Awards Section
  - Experience Timeline & Interactive Tech Stack Grid
  - Quick Copy Contact Section & Social Links

### How to Run v1 Standalone (if needed):
```bash
cd v1
npm install
npm run dev
```
